# Мозаика Мира — фото-пятнашки 3×3 (World Mosaic)

Увлекательная головоломка в формате классических пятнашек **3×3**, выполненная в эстетике неоновой экспедиции **LUMEN**. Восстанавливайте панорамные снимки **50 живописных уголков планеты** в 5 тематических главах и собирайте собственный Атлас Мира.

---

## ✨ Основные возможности

- **50 авторских локаций в 5 главах:** от северных фьордов и океанских лагун до пустынных каньонов, горных перевалов и полярных сияний.
- **Честный решатель на базе BFS/A\*:** каждая партия гарантированно решаема, а компас-подсказка автоматически прокладывает ~80% кратчайшего пути, оставляя финальные ходы игроку для самостоятельного решения.
- **Аудиосистема (WebAudio + iOS fallback):**
  - Тихая, спокойная эмбиент-музыка на фоне (тёплые аккордовые пэды и мягкие переборы с пространственным эхом).
  - Приятные звуковые эффекты перемещения плиток, побед и наград, адаптированные под мобильные браузеры (включая iOS Safari).
- **Две темы оформления:** «Полярная ночь» (тёмная) и «Золотой час» (светлая) с повышенной контрастностью всех текстов и акцентов.
- **Два языка интерфейса:** русский (`RU`) и английский (`EN`).
- **Интеграция с Яндекс Играми (Yandex Games SDK):** поддержка полноэкранной рекламы, рекламы за вознаграждение, внутриигровых покупок и безопасной работы в демо-режиме в обычном браузере.

---

## 💰 Экономика и баланс

- **Стартовый запас:** `120` монет, `2` бесплатные подсказки, `5` единиц энергии.
- **Энергия:** `1` заряд на старт новой сборки; автоматическое восстановление `+1` за 15 минут (максимум `5`, с Премиумом — `8`).
- **Награда за прохождение уровня:**
  - Первое открытие локации: `8 + 5 × звёзды` (`13`–`23` монеты).
  - Повторная сборка: `2` монеты.
  - Возможность удвоить награду (`×2 за рекламу`) на экране победы.
- **Подсказки:**
  - Первые `2` подсказки доступны бесплатно со старта.
  - После их использования базовая стоимость подсказки составляет `(40 + 2 × номер локации, округлено до 5) × 2` (`80`–`280` монет).
  - Набор из 5 подсказок в магазине: `400` монет.
- **Бонусы за рекламу (с суточными лимитами):**
  - `+40` монет за рекламу (до 5 раз в сутки).
  - `+3` энергии за рекламу (до 4 раз в сутки).
  - Бесплатная подсказка за рекламу при нехватке монет (до 4 раз в сутки).

## 🛠 Установка и сборка

### Требования
- **Node.js** 18+ и **npm**

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

### Сборка продакшн-версии
```bash
npm run build
```
После выполнения команды готовая сборка создаётся в папке `dist/` (с поддержкой `vite-plugin-singlefile` в единый `dist/index.html`, готовый к загрузке на Яндекс Игры или любой статический хостинг).

### Предпросмотр собранной версии
```bash
npm run preview
```

## 📂 Структура проекта

- `src/App.tsx` — корневой компонент, состояние сохранения, навигация, реклама и покупки.
- `src/data/economy.ts` — конфигурация экономики, расчёт цен подсказок, наград и регенерации энергии.
- `src/data/levels.ts` — 50 уровней, разбитых на 5 глав экспедиции.
- `src/game/logic.ts` и `src/game/solver.ts` — игровая логика пятнашек 3×3 и поиск кратчайшего решения.
- `src/lib/sound.ts` — генератор звуковых эффектов и спокойной фоновой эмбиент-музыки на WebAudio API.
- `src/lib/i18n.ts` — словари локализации (`RU` / `EN`).
- `src/components/` — экран игры (`GameScreen`), поле (`PuzzleBoard`), атлас (`CollectionScreen`), магазин (`ShopScreen`), шапка (`Header`) и модальные окна (`Overlays`).
